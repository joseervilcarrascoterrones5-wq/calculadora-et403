# Calculadora y Conversor de Medidas - ET403

Este proyecto es una aplicación web interactiva desarrollada para el curso de Programación Web. Integra dos herramientas en una sola interfaz, separando correctamente la estructura (HTML), el diseño (CSS) y el comportamiento (JavaScript).

1. **Calculadora Física:** Interfaz interactiva modo oscuro (estilo neón) que realiza operaciones aritméticas básicas (suma, resta, multiplicación y división). Implementa validaciones estrictas para prevenir cálculos con campos vacíos, caracteres no numéricos y bloquea la indeterminación matemática de la división por cero.
2. **Conversor de Unidades:** Herramienta para convertir medidas de longitud (metros a centímetros y viceversa) y masa (kilogramos a gramos y viceversa), rechazando entradas vacías, letras y números negativos.

## Instrucciones de Uso
- **Calculadora:** Utiliza el teclado interactivo en pantalla para ingresar las cifras y el operador deseado. Presiona el botón azul `=` para ejecutar el cálculo. Usa `AC` para limpiar todo o `⌫` para borrar el último dígito.
- **Conversor:** Escribe un valor numérico positivo en la casilla blanca, elige la unidad de conversión en la lista desplegable y presiona el botón "Convertir" para ver el resultado en la caja verde inferior.
